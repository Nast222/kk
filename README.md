# Movie Library

## Автор: [Логинова]
## Описание:
Приложение для хранения личной кинотеки с фильтрацией по жанру и году, сохранением данных в JSON и проверкой ввода.
## Возможности:
- Добавление фильмов.
- Фильтрация по жанру и году.
- Сохранение/загрузка через JSON.
- Валидация данных.
## Примеры использования:
1. Запустите `movie_library.py`.
2. Введите данные о фильме и нажмите «Добавить фильм».
3. Используйте фильтры для поиска.
4. Сохраните библиотеку кнопкой «Сохранить в JSON».
5. Загрузите данные кнопкой «Загрузить из JSON».
## Технологии:
- Python 3.x.
- Tkinter.
- JSON.
- Git.
