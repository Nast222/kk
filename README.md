# 🌤️ Weather Diary — Дневник погоды

## Описание программы

Простое приложение с графическим интерфейсом для ведения дневника погоды. Позволяет добавлять записи о погоде за определённую дату с указанием температуры и описанием. Данные сохраняются в файл `weather.json` и могут быть загружены обратно.

## Технологии

*   **Python** — язык программирования.
*   **Tkinter** — стандартная библиотека для создания GUI.
*   **JSON** — формат хранения данных.
*   **Git** — система контроля версий.
*   **GitHub** — удалённое хранилище кода.

## Как запустить приложение

1.  Убедитесь, что у вас установлен **Python 3.x**.
2.  Скачайте или клонируйте этот репозиторий на свой компьютер.
3.  Откройте терминал в папке проекта.
4.  Запустите приложение командой:
    ```bash
    python weather_diary.py
    ```
5.  Интерфейс программы откроется автоматически.

## Использование программы

### Добавление записи:
1.  Заполните все поля: **Дата** (формат ГГГГ-ММ-ДД), **Температура** (число), **Описание** (текст), выберите **Осадки** («Да» или «Нет»).
2.  Нажмите кнопку «**Добавить запись**».
3.  Запись появится в таблице. Если данные введены неверно (например, неправильный формат даты), появится сообщение об ошибке.

### Фильтрация записей:
1.  Введите дату в поле «**Фильтр по дате**», чтобы увидеть записи только за этот день.
2.  Введите число в поле «**Фильтр по температуре (выше)**», чтобы увидеть только те дни, когда температура была выше указанного значения.
3.  Нажмите кнопку «**Фильтровать**».
4.  Чтобы показать все записи снова — очистите поля фильтров и нажмите «Фильтровать».

### Сохранение и загрузка данных:
*   **Сохранить в JSON:** Нажмите эту кнопку для сохранения всех записей из таблицы в файл `weather.json`.
*   **Загрузить из JSON:** Загружает данные из файла `weather.json` в таблицу.
